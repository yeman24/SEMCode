# Contributing to SEMCode

Open **Issues → New issue → Bug report** to report a problem. Include the steps to reproduce it, the expected behavior, and the actual result.

The template applies `bug` and `status: needs triage`. Once someone starts working on a confirmed bug, replace the status label with `status: in progress`. Close the issue once the fix is merged.

For a code change, open a pull request and describe how you tested it. If the pull request fixes an issue, add `Closes #123` to the description with the actual issue number.
