# Use Case 5: Add New Employee

## Goal in Context
As a HR Advisor, I want to add a new employee's details so that I can perform my HR responsibilities.

## Scope
HR System

## Level
User goal

## Preconditions
The user is authorised and the database is available.

## Success Condition
The system successfully provides a new employee record.

## Failed Condition
The operation fails and the system displays an error.

## Primary Actor
HR Advisor

## Trigger
The actor selects "Add New Employee" in the HR system.

## Main Success Scenario
1. The actor selects the required feature.
2. The system requests any necessary information.
3. The actor enters the information.
4. The system validates the request.
5. The system communicates with the employee database.
6. The system provides a new employee record.
7. The system confirms successful completion.

## Extensions
- Invalid information: Display an error.
- Record not found: Display a message.
- Database unavailable: Display an error.

## Sub-variations
The actor can select different employee records or report filters.
